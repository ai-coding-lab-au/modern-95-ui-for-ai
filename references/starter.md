# 内容工作台 Starter

本 Starter 提供有作用域的 HTML/CSS 与少量弹窗辅助函数，强调统一结构和低视觉杂乱度。Handover 仍是任务型工作台及原生标题栏的优先参考。

## 选用与接入

先读 [USAGE](../assets/starter/USAGE.md)，再打开 [状态展示](../assets/starter/index.html)。选取与任务相关的结构和组件，沿用项目的框架、状态管理及业务校验。已有成熟组件时，只接入所需的主题与布局规则。

- 单一应用标题栏统领导航、工具区和内容区；应用容器持有连续外框，内部区块使用分隔线。
- 同类控件共享尺寸和常态，主要动作使用深蓝；筛选、选中和键盘焦点分别表达。
- 卡片正文承担弹性空间，底部动作共享基线；颜色分类用局部标记，保留业务含义。
- 编辑弹窗分为标题、可滚内容和动作区。字段校验、草稿保护、写入成功及失败均由业务层决定。

`m95.css` 的规则限定在 `.m95` 内。青绿桌面需要显式使用 `.m95-desktop`；嵌入项目时只添加主题容器。弹窗及其他 portal 节点要位于主题容器中或自行带上 `.m95`，并继承项目覆盖的变量。默认 Segoe UI，可通过 `--m95-font` 覆盖；配色、30 px 控件和 4 px 圆角沿用原数值基线。

普通链接用于页面导航；`aria-pressed` 用于筛选按钮；真实流程步骤使用有序结构与当前步骤标记。不要为套同一外观混用这三种含义。

## 两种任务参考

- [设备清单与详情](../assets/starter/examples/assets.html)：表格、筛选、详情编辑与持久化。
- [服务申请向导](../assets/starter/examples/request.html)：逐步校验、返回修改、取消和确认保存。

案例使用合成数据和各自命名的本机存储，不提供远程服务。复用产品结构时替换案例的数据层；保持原产品已有的保存、权限和错误处理约定。Storage 的写入异常应留住当前编辑内容并给出失败提示，成功提示只在写入成功后显示。

## 验证新的接入

先完成一条实际工作流，再对照状态展示检查主要／次要动作、筛选、错误、禁用、焦点及长内容。窄窗口同时核对页面宽度、内部滚动、末项和操作区可达性。需要调整共用 CSS 时，以两个不同任务案例检查影响；应用专属布局保留在应用中。

本 Starter 是可复制的参考实现，不要求所有页面采用侧栏或卡片，也不要求迁移框架。数值基线保持原样。验证范围见 [验证说明](../docs/validation.md)，来源见 [来源与许可](../docs/source-and-license.md)。
