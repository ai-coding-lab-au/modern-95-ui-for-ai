# 原生桌面适配与验收

用于 Tk/ttk、Qt 等原生控件、WebView 宿主与桌面窗口集成，配合 [设计规范](design-system.md) 阅读。按当前修改选择相关项目；局部修边不要求重跑整套业务、缩放矩阵或打包流程。

沿用已确认的 4 px 圆角、30 px 紧凑密度等视觉基线。原生尺寸需结合字体、边框和实际缩放换算；产品专用密度另存命名变体。下列 Tk、Qt、pywebview 和 Windows 细节是适配线索，具体实现由目标框架决定。

## 圆角合成与线宽

- 在实际父表面上检查最终控件的四角及普通、选中、焦点、禁用等受影响状态。RGBA 源图之外，原生控件可能先填充一个矩形底色；仅看源图会漏掉透出的方形色块。
- 主题自有控件的角外底色匹配可见父表面。嵌套容器分别处理角外底色与内部内容面：灰背景上的白卡片，卡片内按钮按白面合成。第三方样式沿用其主题边界。
- 图像切片边界、布局内边距和最小请求尺寸分开设置。切片应保留曲线及抗锯齿过渡；调整后核对控件高度与文本视口。
- 分别检查合成像素和设计一致性：前者与原生源图合成后的预期像素比较，后者比较相邻控件的曲线、边线和焦点线宽。抗锯齿边缘允许合理量化误差，容差须有依据。
- 修内高光／内影时，对照修前外形、四边外边框及中央内容，并抽查未受影响的角色和状态；保留 alpha 外形、切片边界、padding 与最小尺寸。若测量边框实色核心，注明颜色容差、扫描区域和缩放；核心计数为零可能源于抗锯齿，需结合可见轮廓判断。

## 输入、选择与混合输入方式

- 改外壳时保留原生文本区、校验、选区、只读／禁用、弹出列表和事件绑定链。用最长的真实格式值检查非空字段；核对箭头槽及内边距占用后的文本空间。
- 实际操作覆盖鼠标箭头弹出、Return 选择、方向键、Escape、Tab／Shift+Tab，以及相关编辑、删除和校验路径。程序化设值单独记录。
- 按 [焦点与选中规则](design-system.md) 检查鼠标取消后悬停／移开、点击空白后按 Space、键盘切换及禁用不可激活。保留逻辑焦点，按输入方式表达焦点提示；输入框的编辑焦点与文字选区单独处理。
- Tk 适配需注意主题箭头槽的物理像素取整、只读文本选区与业务选中的区别。新增输入方式绑定时保留原绑定链，避免重复安装；具体状态位和清理选区策略留在项目实现中。

## 控件替换与操作语义

- 替换控件或经授权迁移框架时，以实际产品版本的入口、事件、保存和关闭保护为行为基线；视觉案例只提供外观参考。复用业务逻辑时用窄适配层隔离 UI 与数据路径。
- 修改共享绘制器前列出实际使用者，优先以组件或显式主题选项限定作用域。确需替换共享类／全局绘制方法时，抽查各角色及派生样式，保留事件链与关闭保护；未覆盖的页面、弹窗列为待验收。
- 分开表示焦点／当前行、选中集合、分组节点和业务对象 ID。清空选择后测试复制、编辑和切换动作；按产品规则决定目标。Qt 的当前索引独立于选择变化，不能统一把 `currentIndex` 当作业务选择，也不应全局禁用它。[Qt 选择模型](https://doc.qt.io/qt-6/qitemselectionmodel.html#selectionChanged)
- 弹窗首次显示、编辑后及再次显示时，分别检查输入区 Enter、默认按钮和显式按钮激活。需要禁止输入区隐式保存时，在显示后的实际状态验证；保留按钮自身的键盘激活能力，避免全局拦截 Enter。[Qt 默认按钮](https://doc.qt.io/qt-6/qpushbutton.html#default-prop)
- 非模态窗口的“恢复已有实例”“切换业务对象”“取消后重新打开”分别测试草稿与目标对象。最小化再恢复时保留原最大化状态和未保存内容；按真实操作核对结果。

## 原文显示与异步归属

- 姓名、备注和错误详情等需要原样显示的内容，显式使用纯文本模式。长内容按用途可选择、可滚动，确认动作始终可达；危险操作保留警告、按钮角色及默认焦点。[Qt 文本格式](https://doc.qt.io/qt-6/qlabel.html#textFormat-prop)
- 剪贴板读取、后台任务等异步入口，按业务事件发生的时点固定所属对象、日期和版本。期间切换页面／对象、取消或销毁窗口时，核对迟到结果及读取失败；回调使用仍有效的模型或明确快照。涉及保存时检查合成记录实际归属，快照时点按入口语义决定。

纯文本最小样本：第一行是字面量 `<b>Important</b> &amp;`，第二行是 `Next line`，两行之间使用真实换行。验收时核对文本格式属性及实际画面：标签、实体应原样可见，换行保留。可增加未知标签 `<tag>`，但它单独显示为原文不能证明已禁用自动富文本判断。Qt 接入可对照 AutoText 与 PlainText；该样本无需图片、文件或网络访问。

## 业务行、容量与整页

- 等高测量包含业务派生样式。按字体行高、实际缩放及原生边框计算 padding，读取渲染后的几何；需要同排齐平时使用布局填充，并检查内容裁切和拉伸。
- 紧凑变体同时检查背景图固有最小尺寸、按钮字面比例与控件外间距。图片的尺寸下限可能抵消 padding 的收紧。
- 用项目实际最大容量和完整页面验收，计入标题栏、边框、主／二级导航、摘要、操作区及页尾；嵌套滚动条的占用也计入视口。外壳尺寸变化后重新测量内容区，几像素的高度缺口也可能引发纵向滚动并挤占横向空间；优先调整布局分配与外层留白，保持可读字号、业务行和关键动作。布局样本不改变业务数量限制。
- 给可伸缩内容分配剩余高度；溢出时末行、末列、长错误和全部动作可达。弹窗操作区与滚动内容分开布局，检查最小窗口、聚焦自动露出字段及错误出现后的输入保留。

## 缩放、缓存与绘制

- 分别记录系统 DPI／文字缩放、框架请求缩放、实际回读缩放和窗口尺寸。Tk scaling 可能量化；确认测试字体度量也随之更新，再测几何。
- 先声明边框／焦点线目标为逻辑单位还是设备像素，再选择绘制方式。Qt 默认绘制坐标为设备无关单位，零宽 cosmetic pen 用于一设备像素线；仅按该笔画目标处理，勿把布局、字体或全部线宽统一除以 DPR。截图中发生颜色变化的行数还包含抗锯齿覆盖，须结合实色核心、轮廓连续性和可见焦点判断。[Qt 高 DPI](https://doc.qt.io/qt-6/highdpi.html)、[QPen](https://doc.qt.io/qt-6/qpen.html#isCosmetic)
- WebView 另记 CSS viewport、原生窗口矩形和显示器工作区；比较边界时先统一坐标体系，指针位移按实际 DPI 换算。边框计算值可能是小数，结合截图核对连续性与视觉重量。
- 分数 DPR 下，以宿主实际分配的物理尺寸建立离屏图像；绘制、文本区、箭头与命中边界使用一致的换算约定。发现一像素缺口时，分别核对宿主分配、自有计算和测试夹具的绝对坐标、偏移及取整，修正发生偏差的一层；避免全局替换取整函数或放宽像素容差。[Qt 高 DPI 坐标与图像](https://doc.qt.io/qt-6/highdpi.html)
- 缓存键和原生资源名称使用一致的规范化及取整规则。选相邻缩放边界并往返测试，检查资源复用和重名；图标缓存还应区分方向。
- 遇到切页卡顿时，分开测首次加载、稳定切换、业务重载、图片解码／上传和实际绘制。各页最终几何与异步拟合完成后再测暖切换，记录耗时及环境。
- 小图平铺也可能带来绘制成本。若调整图像均匀中心区域以减少平铺，保持布局最小尺寸及视觉效果；缓存断言与耗时分别报告。

## 原生外框与成品入口

- 按设计规范的单层外壳规则选择宿主模式，保留包含实际窗口边界的整窗证据。自绘标题栏接入真实窗口动作，按钮与输入区排除在拖动命中区外；保留双击最大化／还原、可用边缘缩放、最小尺寸及既有关闭流程，包括正在执行的导出。
- 自绘按钮几何或命中区变化时，在真实窗口中检查按钮中心、矩形内靠近四角及四边中点的位置，并检查相邻窗口缩放边缘。按钮可见交互面内的命中优先级与绘制一致，面外保留平台缩放能力；原生命中返回、按下／释放分派和实际动作分别验证。
- 标题栏高度或边框变化时，同步更新客户区与弹窗装饰余量，覆盖正常、最大化及反复还原。平台提供待应用的窗口外矩形时，用其尺寸与屏幕原点计算，避免沿用移动前的位置；分数缩放下根据取整后的按钮高度与上下留白核对可用区，检查裁切及反复还原后的尺寸累积变化。
- 首次显示时，在工作区能容纳产品最小尺寸的前提下约束窗口大小与位置；最小尺寸放不下时记录冲突并做项目布局适配。分别检查初始、最大化和还原状态；最大化对齐显示器工作区并保留任务栏，按钮图标与提示同步真实状态。自动化恢复窗口采用平台支持的正常路径，绘制异常先核对测试是否改变了窗口状态。
- 独立绘制的标题栏等表面单独检查常态、悬停、按下、移出／取消及平台支持的窗口非活动态。按状态统一决定面色、边色、图标色和凸起线，悬停与按下有可区分的反馈；热态清除不属于该状态的常态装饰。具体颜色沿用产品已确认的方案。
- 状态配色修正保留按钮尺寸、间距、图标坐标与既有按下位移，以及命中区、指针捕获、事件分派和窗口动作。对照该按钮之外的区域，操作回归覆盖拖出取消、最小化／最大化／还原及关闭保护。
- 外框定制按平台能力实现并保留回退模式。保留系统外壳时同步隐藏自绘标题栏、重复外框及自定义缩放命中区；是否接管系统边框由产品需求决定。
- 涉及构建交付时，读回受测源码、成品内置代码／版本及用户实际启动路径，核对快捷入口指向；保持测试与构建依赖环境一致。校验失败停止部署并保留旧版。
- 启动时嵌入 WebView 的 HTML／CSS／JS，在磁盘更新后需正常重开目标程序并核对实际加载版本。窗口宿主代码变更按打包方式重建，外部资源变更核对成品及便携包；运行中的旧窗口不作为新资源的验证目标。

## 证据与适用范围

- 几何、行为、业务语义、像素合成和用户观感分别记录。区分实际页面故障与合成背景下发现的复用风险，以及局部样本与整页结果。
- 分列逻辑测试、组件视觉、原生窗口操作和成品／启动入口核对；按修改范围选择检查，逻辑测试数量不代替列表边框等视觉状态覆盖。
- 测试结果绑定源码版本、相关依赖、命令和完整退出摘要；长任务等待原进程及相关子进程结束后判定。修改共享类时，核对实际页面、编辑器和成品入口确实使用该实现。新增反例单列本轮覆盖，同一检查集在不同缩放下分别计数，避免累加为独立功能数量。
- 整窗截图记录目标进程／窗口标识、捕获方法并逐张检查成图内容、状态与边界。屏幕区域截图在捕获时确认目标仍在前台且未被遮挡；按窗口句柄捕获也要检查空白、遗漏的合成层或其他窗口内容。替换错误证据后重新打包并核对清单；浏览器元素截图用于局部组件，宿主外壳使用原生整窗证据。所有捕获方式以当前环境许可为前提。
- 状态截图先等待窗口映射、布局和焦点稳定，再施加目标状态；捕获前后核验状态，并检查对应绘制结果。请求了 hover 而事件未送达时，该项标为未覆盖；放宽断言后的退出码 0 不改变覆盖状态。误标截图记录为夹具／取证问题，修正后另存版本化证据，保留历史失败记录。
- 绘制前后对照先划定允许变化区和保持区，保留不可变旧基线。有意改变的标题栏比例、图标或尺寸按新设计验收，其余区域沿用原有约束；状态对照使用相同几何、背景和捕获条件。按实际方法分别标注输入消息测试、窗口捕获、GDI 注入回放、物理指针操作和屏幕合成器表现；受控回放验证绘制，原生操作另行验证。
- 几何回放按真实平台事件语义提供每次输入。若计算会就地改写外框矩形为客户区，下一次调用重新提供对应外框；发现累积缩小时先核对夹具输入，再判断产品行为。修正夹具后保留失败记录并重跑相关检查。
- 只使用当前环境允许的操作和捕获方式。截图失败时先检查窗口映射、字体刷新、遍历事件及样本是否超出工作区；修正夹具后重新取证。工具受限的项目记未执行。
- 合成缩放、真实系统 DPI、跨屏移动与辅助技术分别列验证范围。来源项目的测试注明“报告结果”；独立复验和用户视觉确认各列状态。
- 经验记录只提交获准分享的脱敏材料；合成数据仍可能暴露产品流程、内部配置和缺陷细节。原文件与私有哈希留在来源项目，公开反馈使用通用描述及重新制作的最小示例，见 [贡献规则](../CONTRIBUTING.md)。

相关检查可按以下短模板记录；本机完整路径和原始日志保留在私有记录，分享前换成别名：

```text
受测版本／实际入口：
框架、系统、窗口尺寸；请求缩放／实际回读／真实系统缩放：
证据方式：逻辑／离屏／浏览器／原生操作／用户报告
目标状态／实际送达状态／观察结果：
独立用例数 × 环境数；失败／跳过／未覆盖：
命令、退出码、异常日志；证据位置：
数据隔离与自身进程清理（涉及运行入口时）：
归因：共享规范／项目适配／既有产品／取证问题／偏好／待核实
```

异步回调或槽函数异常可能只出现在日志中；同时检查错误记录、预期结果和进程退出码。合成入口反例与真实产品故障分别记录。

## 合成预览入口的数据边界

仅在创建或启动项目适配预览、测试入口时使用本节。导入应用前确认数据库、偏好、缓存和临时目录的配置顺序；除显式参数外，检查继承环境、工作目录及备用配置。验证实际解析路径及读写位置都属于本轮沙箱。

使用沙箱内的合成外部候选目录与哨兵检查意外继承，避免读取真实用户配置来验证隔离。启动、取消、失败和正常退出后分别检查残留目录、文件与自有进程；只清理确认属于本次运行的对象。正式产品的保存和关闭保护按原业务规则保留。共享 skill 提供检查方法，具体路径修复由来源项目完成。

反馈来源和本轮纳入范围见 [迭代与来源](evolution.md)。
