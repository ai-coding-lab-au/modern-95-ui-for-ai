# Source and license scope

This is a curated snapshot of Modern 95 UI's current skill, Starter and preferred Handover workbench. It contains no inherited Git history or original business-application source. Historical design experiments, private feedback extracts, audit bundles and application data are excluded.

## Distributed implementation

The Starter and its examples were authored as framework-neutral reference implementations for this design language. Handover was authored from the documented workbench rules and numerical tokens. The public packaging removes Handover's unused dependency on the historical preset model; the same twelve values are already declared in its CSS. Starter components and the approved Handover CSS retain their visual baseline.

The project's own code and documentation are distributed under the root [MIT license](../LICENSE). The standalone Starter includes a matching license for copying. No font files, Microsoft system assets, React95 package or historical external application code are distributed in this snapshot. Windows 95 is a design inspiration; this project is not affiliated with Microsoft.

This scope statement records what is distributed and the available provenance. It is not a blanket claim that all historical development references have been reconstructed.

## Lucide icons

The bundled set contains 21 original SVG files from the pinned Lucide revision, its complete upstream license, a source/hash manifest and deterministic generated markup. Handover uses five of these drawings: clipboard-check, minus, square, copy and x. The complete reviewed subset is retained so its manifest and reproducible module remain intact.

The workbench adapter changes the outer viewBox and stroke scale for optical sizing; original drawing elements remain unchanged. Full upstream ISC and applicable Feather MIT notices remain in the adjacent license. See [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md).
